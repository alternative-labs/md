# `md`

> [!WARNING]
> `md` is under active development; features and interfaces may change.

`md` is a blazing-fast, Rust-powered toolkit for parsing, linting, and formatting Markdown content.

## Project structure

- `src/` — workspace entry point
- `crates/parser/` — Markdown parser crate
- `apps/` — application code and tooling

## Getting started

This project uses Cargo workspaces.

```bash
cargo test
cargo run
```
